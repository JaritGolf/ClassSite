# My Civics Class — Fact Sheet for School and District Staff

**What it is.** A website for practicing 7th grade Florida Civics. Students
work through lessons and quizzes ("missions") and review what they learned.

**The short version.** The website does not know who its students are and does
not keep anything about them.

## What students do

1. Open the site. There is nothing to sign in to — no account, no class code,
   no name.
2. Work through a mission.
3. On passing the final quiz, copy the **completion code** the site shows.
4. Paste the code into the assignment in Google Classroom.

## What the website keeps

| | Kept by the website? |
|---|---|
| Student names, emails, ID numbers | **No** |
| Student accounts or logins | **No — there are none** |
| Class rosters | **No** |
| Scores, answers, grades, progress | **No** |
| ELL, ESE, IEP, reading-level or accommodation information | **No** |
| Information about parents or guardians | **No** |
| Which student used the site, or when | **No** |
| Lessons, questions and vocabulary | Yes |
| The teacher's name and school email (to edit lessons) | Yes |

The website's database has no place to put student information. Automated
checks fail if anyone adds one.

## Where a student's progress lives

On the student's own Chromebook, in the browser. It is not sent to the website
for storage, and it has no name attached. A student can save it to a file (for
example, in their Google Drive) and load it later on a different device.

## How the teacher knows work was done

The completion code. It is a short code such as `MCC-1.1-100-20260914-7K2M9XD4AQ`
that records the mission, the score and the date. The teacher pastes codes into
a "Check codes" page that confirms each one is real. That page saves nothing.

The code does not contain the student's name. The teacher knows whose it is
because the student turned it in through Google Classroom, which the district
already uses.

## Reading supports

Read aloud, one sentence per line, high contrast, large text, extra time, and a
Spanish or Haitian Creole glossary are available to **every** student to switch
on for themselves. Nothing is assigned to a student or labelled, and the
website is not told which supports a student uses.

## The classroom rule

> **Students never type their name — or anyone else's — into this site.**

The site never asks for a name. The rule covers the few places a student can
type, and it applies to the teacher too: no student names or photos in lesson
text, uploaded pictures, or notes for a substitute.

## Plain answers to likely questions

**Does it use tracking or advertising?** No. There is no analytics, advertising
or tracking code.

**Does it contact other companies?** Only if a student clicks to play a lesson
video, which is played by YouTube's privacy-enhanced player. Nothing loads from
YouTube before that click.

**Is anything recorded at all?** The company hosting the website keeps ordinary
web server logs — time, page address and IP address — as every website's host
does. The app itself does not read or keep them, and page addresses name a
lesson, not a student.

**What if a Chromebook is wiped?** Progress on it is gone unless the student
saved a file first. Completion codes already turned in through Google Classroom
are unaffected.

**Can a student share a code with a friend?** Yes. A code proves a mission was
passed, not who passed it. Treat it like any other piece of turned-in work.

**Can the teacher see how a student is doing in the app?** No. The teacher sees
what the student turns in. A student can also print a progress summary from
their own device.

**Who can sign in?** Only the teacher, with their school Google account, and
only if their address is on a list set up for the site.
